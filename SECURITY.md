# Безопасность

Проект — экспериментальный локальный прототип, без гарантированного срока поддержки.
Не отправляйте ключи API и приватные сохранения в публичные issues.

Для сообщения об уязвимости используйте приватный адрес владельца из истории проекта:
villetacore@proton.me. Укажите шаги воспроизведения, версию исходников и возможное влияние.

Ответы модели считаются недоверенным вводом. Не публикуйте сервер LM Studio в интернет
без отдельной настройки аутентификации и сети. Адрес сервера задаёт получателя
контекста персонажей и реплик игрока.
