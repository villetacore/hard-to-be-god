# Изменения

## Unreleased

### Исправлено

- Передача предмета требует близости к реальному получателю и свободной линии между
  персонажами: достижение старой позиции игрока больше не передаёт ему вещь удалённо.
- Загрузка сохранения восстанавливает нулевые отношения, даже если после сохранения
  они изменились: отсутствующие в разреженной записи связи сбрасываются.

### Добавлено

- Регрессионные тесты доставки и восстановления отношений.
- README с галереей, руководство игрока, правила участия, политика безопасности,
  шаблоны issue/PR и CI для тестов и Clippy.
- Единое форматирование Rust-исходников через rustfmt.
- Исключения для IDE, локальных данных, секретов и результатов сборки.

Историческое состояние прототипа описано в docs/PROJECT_AUDIT.md от 18.10.2026.
