# Участие в разработке

Начните с README и docs/ROADMAP.md. Для крупного изменения сначала откройте issue
с проблемой, ожидаемым поведением и предлагаемым объёмом работы.

1. Создайте ветку от актуальной основной ветки.
2. Воспроизведите ошибку; для изменений логики добавьте регрессионный тест.
3. Выполните `cargo test --locked` и `cargo clippy --locked -- -D warnings`.
4. Для визуальных изменений запустите smoke-режимы и приложите скриншоты.
5. Опишите наблюдаемое поведение, проверки и известные ограничения в pull request.

Не добавляйте `target/`, `saves/`, настройки IDE, токены, персональные пути или архивы ассетов.
`Cargo.lock` хранится в Git: это приложение. Общий `ai_config.json` содержит только
безопасные значения по умолчанию. Для новых ассетов укажите источник и лицензию.

Сохраняйте оригинальное авторство и лицензию. Участники используют собственное авторство;
локальное имя владельца проекта не нужно копировать в настройки других участников.
Сообщения об ошибках не должны содержать API-ключи и личную историю сохранений.
